The Bug
Your SSE hotelProbeCompleted handler updates the progress counter (correctly showing "21 hotels found so far") but does not push the hotel's result object into the array that renders the hotel cards below.

The Fix
In your SSE hotelProbeCompleted event handler, you likely have something like:


// ❌ Current — only updates counter
eventSource.addEventListener('hotelProbeCompleted', (e) => {
  const event = JSON.parse(e.data);
  checkedCount++;
  if (event.status === 'CONFIRMED' || event.status === 'LIMITED') {
    foundCount++;  // ← updates "21 hotels found so far"
    // BUT never adds the hotel to the display list!
  }
});
It needs to also add the hotel to the results array:


// ✅ Fixed — also adds hotel to results list
eventSource.addEventListener('hotelProbeCompleted', (e) => {
  const event = JSON.parse(e.data);
  checkedCount++;
  if (event.status === 'CONFIRMED' || event.status === 'LIMITED') {
    foundCount++;
    // ADD the hotel to the results array that renders cards:
    setHotels(prev => [...prev, event.result]);
  }
});
The hotel object is in event.result — it contains hotelName, starRating, sellingPricePerRoomPerNight, imageUrl, roomsAllocated, etc. (the full shape I documented in the previous message).

Also
The status endpoint response visible in the Network tab shows completed: 43 — that's from a previous finished run. Once the current search finishes (200/200), do a final status call and replace the hotel list with the authoritative data:


// When progress reaches 100%
const res = await fetch(`/api/v1/requests/${requestId}/hotel-search/status`);
const { data } = await res.json();
const finalHotels = data.jobs
  .filter(j => j.status === 'COMPLETED' && j.resultJson)
  .map(j => j.resultJson);
setHotels(finalHotels);  // replace with authoritative list
